# ai-crawlers

Machine-readable dataset of AI crawler user-agents with weekly verification.

## For AI agents

- JSON data at `crawlers.json`, validated against `schema.json`
- README is auto-generated by `generate_readme.py`
- To add a crawler: edit `crawlers.json`, run `generate_readme.py`, commit both
- Weekly verify Action checks vendor docs URLs
- Sibling repos: awesome-ai-visibility, geo-audit-skill, geo-prompts
